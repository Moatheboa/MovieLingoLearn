A not yet finished project where the user, much like in duo lingo, practices language by translating sentences from english to spanish.
The sentences come from real movie subtitles, that are being read from csv-files.
Now a user can create a new login and then log in, but not yet log out. 
When the user has completed all sentences in the database (for testing purposes it is now only 3), there is a redirect back to the first sentence so that it can all be done again.
